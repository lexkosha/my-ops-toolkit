# Окружение MongoDB и Redis (Docker Compose)

[🇬🇧 English Version](../eng/mongo-and-redis.md)

---

Данная конфигурация предназначена для быстрой сборки и локального запуска баз данных MongoDB и Redis, которые используются в работе парсера.

### Предварительные требования
Перед запуском убедитесь, что в вашей системе установлены:
* **Docker**
* **Docker Compose**

> [!WARNING]
> **Важно по безопасности:** Перед запуском обязательно откройте файл `docker-compose.yml` и измените стандартные данные авторизации в блоке `environment` на свои собственные:
> * `MONGO_INITDB_ROOT_USERNAME` (логин администратора MongoDB)
> * `MONGO_INITDB_ROOT_PASSWORD` (пароль администратора MongoDB)
>
> Также не забудьте изменить пароль для Redis в строке запуска: `--requirepass ваш_новый_пароль`. Не оставляйте стандартные пароли, если планируете использовать базы вне локальной машины!

### Инструкция по запуску
1. Откройте терминал и перейдите в папку с файлом конфигурации:
   ```bash
   cd ../../mongo-and-redis
   ```
2. Разверните контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```

### Настройки подключения (для парсера)
Если ваш скрипт-парсер работает непосредственно на хост-машине (вне Docker-контейнера), используйте следующие параметры:

* **MongoDB URI:** `mongodb://root:secretpassword@localhost:27017/`
* **Redis URL:** `redis://:redispassword@localhost:6379`

### Управление контейнерами
* **Проверить статус работы:** `docker compose ps`
* **Посмотреть логи баз данных:** `docker compose logs -f`
* **Остановить и удалить контейнеры:** `docker compose down`
