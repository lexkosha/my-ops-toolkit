# Окружение MongoDB и Redis (Docker Compose)

[🇬🇧 English Version](../eng/mongo-and-redis.md)

---

Данная конфигурация предназначена для быстрой сборки и локального запуска баз данных MongoDB и Redis, которые используются в работе парсера.

### Предварительные требования
Перед запуском убедитесь, что в вашей системе установлены:
* **Docker**
* **Docker Compose**

---

### 🔐 Важно: Безопасность и файл .env

Хранить пароли в открытом виде внутри файла `docker-compose.yml` крайне небезопасно, особенно при публикации проекта на GitHub. Лучший способ защитить данные — использовать переменные окружения через файл `.env`.

#### Что нужно сделать для замены:

1. В папке `mongo-and-redis/` рядом с файлом `docker-compose.yml` создайте текстовый файл с именем `.env`.
2. Скопируйте в него следующие строки и укажите свои надежные данные:
   ```env
   MONGO_ROOT_USER=ваш_логин_администратора
   MONGO_ROOT_PASSWORD=ваш_сложный_пароль
   REDIS_PASSWORD=ваш_пароль_для_редиса
   ```
3. Docker Compose автоматически подтянет эти значения в конфигурацию при запуске.

> [!WARNING]
> **Внимание:** Никогда не отправляйте файл `.env` в публичный репозиторий! Обязательно добавьте строку `.env` в ваш файл `.gitignore`.

---

### Инструкция по запуску
1. Откройте терминал и перейдите в папку с файлом конфигурации:
   ```bash
   cd ../../mongo-and-redis
   ```
2. Разверните контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```

### Настройки подключения (для парсера)
Если ваш скрипт-парсер работает непосредственно на хост-машине (вне Docker-контейнера), используйте для подключения те данные, которые вы указали в файле `.env`:

* **MongoDB URI:** `mongodb://<MONGO_ROOT_USER>:<MONGO_ROOT_PASSWORD>@localhost:27017/`
* **Redis URL:** `redis://:<REDIS_PASSWORD>@localhost:6379`

### Управление контейнерами
* **Проверить замену переменных (без запуска):** `docker compose config`
* **Проверить статус работы:** `docker compose ps`
* **Посмотреть логи баз данных:** `docker compose logs -f`
* **Остановить и удалить контейнеры:** `docker compose down`
